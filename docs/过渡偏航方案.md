# 垂起往固飞过渡：偏航修正的两个方案

本分支落地的是方案 B，固件 `ArduPlane V4.6.3-thstfac-qyaw`（Release 标签 `firmware-qyaw`）。下面「现在发生什么」是没打这个补丁时的行为。过渡相位见 [flight-modes.md](./flight-modes.md)，脚本见 [`lua/tilttri_fw_tilt_aileron.lua`](../lua/tilttri_fw_tilt_aileron.lua)。补丁在 [`firmware/patches/plane-4.6.3-qyaw/`](../firmware/patches/plane-4.6.3-qyaw/)，叠在前后推力比补丁之后。

衰减用 Lua 共模 PWM 反推前倾角（`qhold` 里固件 `current_tilt` 仍停在垂直），`fade = cos(θ)`，垂直为 1，固件认为的水平为 0。`fade < 0.05` 时差动不再加上，并在 `rate_controller_run()` 之前清掉偏航目标、角速度和 I。横滚项不加到倾转上。

## 现在发生什么

`FLTMODE_CH=0` 时，垂起切固飞后模式先停在 `QSTABILIZE`（地面站 `BTILT: qhold`）。左右倾转只做共模，一起扫向 `BTILT_HORIZ_*`，直到两侧都走过 `BTILT_QFRAC`（默认 0.7，大约还剩 27°）才进入固飞。这段 Lua 用 `update_tilt(false, false)` 把倾转 PWM 盖成共模，vectored yaw 和固飞横滚差动都没有。三电机仍是垂起混控，横滚和俯仰差推力还在。

偏航执行器被盖住，姿态环没有停。`QSTABILIZE` 每个周期仍把方向舵当成目标偏航角速度写进偏航角目标。机头转不过去，角误差被夹在「能让偏航角速度控制器饱和」的上限里，多出来的目标被拉回；偏航角速度 I 项继续积分，直到 `Q_A_RAT_YAW_IMAX`。杆回中只是不再往前推目标，已经形成的角误差和 I 项还在。

拨回垂起时，若还在 `qhold`，模式本来就是 `QSTABILIZE`，不会重置这套状态。回程 Lua 仍共模覆写，修正出不去。舵机回到进入过渡时记下的垂起角、出现 `BTILT: qrecover done`、覆写结束后，固件当前的偏航输出立刻写到左右倾转上，短舱突然差动。`Q_TILT_YAW_ANGLE` 现为 15°，饱和时差动顶到这个角。

油门在底部且没开 airmode 时，`QSTABILIZE` 每圈会 relax 姿态环，台架上油门最低往往看不出这一下。空中油门抬着就会留下。

只把 `Q_A_RAT_YAW_I` 调成 0 不够：角误差还在，松手仍会猛收。

## 方案 A：共模覆写期间清掉偏航记忆

过渡里方向修正仍然不起作用。积下的目标在松开前被清掉，拨回垂起时不再突然转向。

在 Plane 4.6.3 的 `QuadPlane::motors_output()` 里、`rate_controller_run()` 之前，当模式为 `QSTABILIZE` 且左右倾转（功能 75/76）的脚本 PWM 覆写仍有效时，每个周期：

```cpp
attitude_control->reset_yaw_target_and_rate(true);
attitude_control->rate_bf_yaw_target(0);
attitude_control->get_rate_yaw_pid().reset_I();
```

三行都要。只重置角度目标的话，这一拍已经算好的偏航角速度还在，积分会继续涨。横滚和俯仰不要清，这段三电机混控还在用它们。

稳态垂起时 Lua 不覆写倾转，条件不成立，vectored yaw 照常。固飞差动覆写发生在 `STABILIZE` / `MANUAL`，也不会被清掉。`qback` 里积下的偏航，会在随后的 `qrecover` 共模回扫期间被清掉。覆写超时约 60 ms，清状态会多盖住这一小段，避免松手那一拍把旧输出写出去。

单独做一个补丁，不要并进现有的前后推力比补丁（`firmware/patches/plane-4.6.3/`）。Lua 不用改控制逻辑。

代价：`qhold` 和共模回扫期间打方向舵，短舱和机头都不跟。

## 方案 B：过渡中保持 vectored yaw

方向修正在倾转过程中继续起作用，松手时不再有一截被藏住的差动。积分只有在机头真的跟上目标角速度时才会消掉。

短舱越往前倾，同样的左右差动越不像偏航、越像横滚。接近垂直时可以保留；靠近水平时应衰减到 0，否则打方向会带进滚转。衰减到 0 的那一段执行器又被拿走，仍要按方案 A 清偏航目标和积分，否则末段还是会积。

不能只在 Lua 里按方向舵杆量加差动。`set_output_pwm_chan_timeout` 生效后，通道算出的倾转 PWM 不再更新，脚本读回的是自己上一拍的共模值，不是固件这一拍的偏航差动。杆量差动只跟手指走，跟不上姿态环里那份角误差和 I 项，松手时仍可能猛收。

要让控制器自己的差动留在舵机上，应在固件里把 vectored yaw 叠到 Lua 的共模中心上，并随前倾角衰减。这比方案 A 改动大，过渡手感也会变：前半段打方向短舱会差动，后半段差动逐渐消失。本分支按这个做法实现。

台架上桨不产生偏航力矩时机头不动，积分仍会涨。舵机若已经带着这份差动，松开时不会再跳一截，但差动会一直留在短舱上，直到真的转起来或被清掉。

## 怎么选

| | 方案 A | 方案 B |
|---|---|---|
| 过渡中打方向 | 不起作用 | 接近垂直时起作用，靠近水平时衰减 |
| 拨回垂起的突然差动 | 去掉 | 去掉（衰减段仍要清状态） |
| 改哪里 | 固件一小段；Lua 不改行为 | 固件把偏航差动叠到共模中心并衰减；衰减段同 A |
| 手感 | 与现在相同，只是不再猛收 | 过渡中段会有偏航，并带一点滚转耦合 |

只为了去掉拨回垂起时的突然转向，先试方案 A。若过渡中必须能改方向，再试方案 B，不要用 Lua 杆量差动代替。

## 台架怎么看

油门要抬起来。油门在底部时 relax 会把问题藏住。拆桨。

方案 A：进入 `qhold`，压住方向舵大约一秒，杆回中再拨回垂起。`qrecover done` 时 S5/S6 应停在记下的垂起角，不应再突然差动。之后稳态 `QSTABILIZE` 打方向，S5/S6 仍要差动。

方案 B：同一段里压方向，S5/S6 应在共模扫角上立刻差动，且越接近水平差动越小。拨回后不应在 `qrecover done` 再多跳一截。稳态垂起的 vectored yaw 仍要在。
